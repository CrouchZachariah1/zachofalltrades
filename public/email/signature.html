Email signatures

Same mark and contact block for every mailbox. Open this page, highlight the white signature, copy, then paste into the HTML signature field for that identity. Images load from zachofalltrades.co.za.

How to install

  1. Open webmail for zachofalltrades.co.za and edit the identity for that address.
  2. Turn the signature field to HTML if it offers a choice.
  3. Copy the signature on the white card below — not this dark page chrome.
  4. Paste, save, then send a test to yourself.

Outlook desktop: File → Options → Mail → Signatures. Paste the copied block. Allow images when you test.
