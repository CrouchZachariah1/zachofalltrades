Email signatures

Truehost Workplace (OX App Suite) shows the tags as text if you paste HTML into the visual box. Copy the HTML code with the button, then paste it in source / HTML view.

Install in Workplace

  1. On this page, click Copy HTML code for that mailbox.
  2. In Workplace: the three-dot menu → Settings → Mail → Signatures → Add new signature.
  3. In the signature editor toolbar, click the source control — labelled <>, HTML, or Source. That switches off the visual box.
  4. Paste (Ctrl+V), then switch back to the visual view. You should see the Z and the layout, not the tags.
  5. Name it, save.
  6. When you compose: Options → HTML (not Text), then pick this signature. Settings → Mail can also set the default compose format to HTML.

If the editor still shows <table> after you paste, you were in visual mode. Delete it, switch to source, paste again.
